# NFCwebPay
**Принимайте оплату и создавайте продвинуту систему внутри ваших объектов/мероприятий**
---
### Концепция проекта
Оплата внутри предприятий или на мероприятиях с помощью RFID, управление картами
через Web-интерфейс(SPA), что позволяет действовать быстро и без дополнительных вложений. А также удобный лог и контроль каждой операции
### Использование технологий
1. SPA(Single Page Application) - использования web-технологий для быстрого развертывания приложения и оперативных действий, вне зависимости от места.
2. webNFC(работа без дополнительных устройств) - вам не нужны дополнительные NFC-reader, используйте любой Android смартфон (с поддержкой NFC и Chrome v89+).
3. RFID карты - удобный физический носитель, который есть у всех.
